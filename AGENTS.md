## Code Review Rules

- Leia a descrição da PR e a issue vinculada para identificar a intenção e os critérios de aceite.
- Compare o diff com essa intenção. Percorra o repositório em busca dos fluxos afetados e confira seus chamadores, testes, configurações e documentação, inclusive fora do diff.
- Para cada achado, cite arquivo, linha, cenário afetado e impacto observável. Se faltar evidência para confirmar um critério, registre a lacuna no parecer interno.
